# 🐾 Happy Tails Pet Store

A modern and responsive pet store web application built with React and Vite. Users can browse pet products, manage their cart, place orders, and view order history through a clean and user-friendly interface.

## Features

* Product browsing and search
* Category-based filtering
* Shopping cart management
* Order placement and order history
* User profile management
* Responsive design for desktop and mobile
* Contact page with store information
* WhatsApp quick contact button

## Tech Stack

* React.js
* Vite
* React Router
* CSS3

## Installation

```bash
npm install
npm run dev
```
